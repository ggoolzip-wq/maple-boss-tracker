# 메이플 보스 트래커 (KMS) — 사용법

## 1. 기본 사용 (설치 필요 없음)
1. `index.html` 파일을 더블클릭해 크롬/엣지에서 엽니다. (파일 하나로 동작, 인터넷 없이도 체크·계산 가능)
2. 왼쪽 **+ 추가**로 캐릭터를 직접 추가하거나, 아래 2번처럼 넥슨 API로 불러옵니다.
3. 데이터는 이 브라우저에만 저장됩니다. 다른 PC로 옮길 때는 **설정 → JSON 내보내기/가져오기**를 쓰세요.
4. 캐릭터 순서: 카드 왼쪽 **⠿ 손잡이를 끌어서**(휴대폰은 손잡이를 누른 채 이동) 또는 **▲/▼** 버튼으로 바꿉니다.
   같은 월드 안에서 순서를 바꾸고, 월드 제목 줄의 ⠿ / ▲▼ 로 월드 순서도 바꿀 수 있습니다. 동기화·불러오기·본캐 지정을 해도 순서는 그대로입니다.
5. **보스 체크** 탭 오른쪽 패널에 이번 주 전체 수익과 캐릭터별 수익이 나옵니다. 주간 수익 = 이번 주 클리어한 **주간 보스**의 결정석 가격 ÷ 파티 인원의 합계(캐릭터당 12회까지, 월드 판매 한도는 계산하지 않음). (좁은 화면에서는 아래쪽)
6. **희귀 드롭 획득 기록**: 보스 행의 아이템 칩을 누르면 그 캐릭터의 이번 주 획득 개수가 +1 됩니다.
   칩의 **−** 버튼(또는 우클릭)으로 1개 취소. 드롭은 **개수만** 기록하고 수익(결정석)에는 넣지 않습니다.
   오른쪽 패널·주간 기록·총 수익 탭에서 캐릭터별/주별/아이템별 획득 개수를 볼 수 있습니다.
   **반지 상자**(녹옥/홍옥/흑옥/백옥/생명)를 누르면 결과 창이 뜹니다: 리스트레인트 링 4레벨 / 컨티뉴어스 링 4레벨 / 둘 다 못 먹음.
   고르면 +1과 결과(리4·컨4·꽝)가 함께 기록되고, 리4·컨4면 축하 연출이 나옵니다. ✕·Esc·바깥 클릭은 아무것도 기록하지 않습니다.
   −(취소)는 가장 최근 획득과 그 결과를 지웁니다. 이 기능 이전에 기록한 반지 상자는 '미기록'으로 표시됩니다.
7. **총 수익** 탭: 처음 기록한 주부터의 누적 수익(주간 보스 + 월간 보스 별도), 모든 주의 막대 그래프와 누적선,
   캐릭터별 누적, 아이템별 누적 획득 개수(반지 상자는 리4·컨4·꽝 집계와 대박 확률), 전체 주 목록. 주간 기록은 자동으로 지워지지 않으며 JSON 백업에 포함됩니다.
   월간 보스(검은 마법사)는 주간 수익에 넣지 않고 **'이번 달 월간 보스'** 로 따로 보여 주며, 매월 1일 초기화 때 **주간 기록** 탭의 '월간 보스 기록'에 저장됩니다.

## 2. 넥슨 Open API 연동 (본캐·부캐 불러오기 + 보스 자동 체크)
1. https://openapi.nexon.com 에 넥슨 ID로 로그인합니다.
2. **마이 페이지 → 애플리케이션 등록** → 게임: 메이플스토리 → API 키 발급 (애플리케이션 상세 화면에서 복사).
3. 트래커의 **설정 · API · 백업** 탭 → **+ 넥슨 계정 추가** → 이름(예: 본계정)과 키 입력.
   키를 입력하면(또는 **연결 테스트 · 캐릭터 목록**을 누르면) 바로 그 계정의 **캐릭터 목록 창**이 열립니다.
   - **부계정이 있으면 계정마다 키를 따로 등록**하세요. 캐릭터 목록·보스 자동 체크는 그 키를 발급한 계정의 캐릭터만 조회됩니다.
4. 목록에서 캐릭터 체크 → **선택 추가**. (나중에는 왼쪽 **계정 캐릭터 불러오기**로 다시 열 수 있고,
   **+ 추가** 창 맨 위의 **이 계정 캐릭터에서 선택** 목록에서 한 명씩 고를 수도 있습니다.)
5. **🔄 지금 동기화**를 누르면 게임 내 "메이플 스케줄러"의 보스 완료 정보로 클리어가 자동 체크되고,
   레벨·직업·이미지·**현재 경험치(%)**도 갱신됩니다. 페이지를 열어 두면 15분마다 자동 동기화합니다.

### 알아 두세요
- 보스 자동 체크는 **내 계정 캐릭터**만, **2026-06-25 이후 한 번 이상 접속한 캐릭터**만 됩니다. 안 되는 캐릭터는 ⚠ 표시 — 손으로 체크하면 됩니다.
- **파티 인원은 API로 알 수 없어서** 보스마다 직접 골라야 합니다(결정석 분배 계산용).
- 레벨·경험치 등 기본 정보는 넥슨 API 기준 시점 데이터라 게임과 약간 차이가 날 수 있습니다. 직접 추가한 캐릭터는 경험치 막대가 표시되지 않습니다.
- API 키는 이 브라우저(localStorage)에만 저장되고, 백업 JSON에는 들어가지 않습니다. 공용 PC에서는 쓰고 나서 키를 지우세요.

### 키를 넣었는데 캐릭터가 안 나올 때
캐릭터 목록 창에 결과가 그대로 표시됩니다.
- **"계정 캐릭터가 0명입니다"** (호출은 성공): 
  1. 키를 발급한 **넥슨 ID**가 게임 캐릭터가 있는 넥슨 ID와 같은지 확인하세요. 캐릭터 목록은 *본인 API 키로만*, 키를 발급한 계정의 캐릭터만 나옵니다
     ([공지 2024-06-07](https://openapi.nexon.com/ko/support/notice/2580334/)).
  2. 키가 `test_`로 시작하면(개발 단계) 본인 계정 데이터가 비어 있다는 사용자 보고가 있습니다
     ([mapleaudit 가이드](https://www.mapleaudit.com/guide), 비공식). 애플리케이션을 **서비스 단계(`live_`)** 로 다시 발급해 보세요
     ([사전 준비 가이드](https://openapi.nexon.com/ko/guide/prepare-in-advance/): 개발 단계 초당 5회·하루 1,000회, 서비스 단계 초당 500회).
  3. 새 캐릭터·새 키는 반영까지 시간이 걸릴 수 있습니다(게임 데이터 평균 15분). 잠시 후 **다시 불러오기**.
- **오류 코드가 보일 때** ([응답 코드표](https://openapi.nexon.com/ko/guide/request-api/)):
  `OPENAPI00005` 잘못된 키(복사 실수·재발급된 키) · `OPENAPI00002`(403) 권한 없음 · `OPENAPI00007`(429) 호출량 초과 ·
  `OPENAPI00009` 데이터 준비 중 · `OPENAPI00010` 게임 점검 · `OPENAPI00011` API 점검. "네트워크 오류"면 설정에서 연결 방식을 **로컬 프록시**로 바꿔 보세요.
- 그래도 안 되면 **+ 추가** → 이름 입력 → **API 조회**로 한 명씩 추가할 수 있습니다.

## 5. (필요할 때만) 로컬 프록시로 실행
보통은 필요 없습니다. "네트워크 오류" 때문에 API 연결이 안 될 때만 쓰세요.
1. 파이썬을 설치합니다 (https://www.python.org — 설치할 때 "Add python.exe to PATH" 체크).
2. Windows: `start-windows.bat` 더블클릭 / Mac: 터미널에서 이 폴더로 이동 후 `python3 serve.py`
3. 브라우저에서 `http://localhost:8787` 을 엽니다(`python serve.py --open` 으로 실행하면 자동으로 열림). **설정 → 연결 방식 → 로컬 프록시**를 고르세요.
4. 종료: 검은 창에서 `Ctrl + C` 또는 창 닫기.
※ 주소가 file:// 에서 localhost 로 바뀌면 브라우저 저장소도 따로라서, 기존 데이터는 JSON 내보내기 → 가져오기로 옮기세요.

## 6. 결정석 가격 갱신 (공식 공지에서 자동으로 가져오기)
패치로 결정 판매 가격이 바뀌면 **설정 → 💎 결정석 가격 → 🔄 결정석 가격 갱신** 버튼으로 공식 가격을 반영할 수 있습니다.

**사용 방법 (데이터 옮길 필요 없음)**
1. 평소처럼 `index.html` 을 더블클릭해서 연 페이지는 **그대로 둡니다.**
2. 이 폴더의 `start-windows.bat` 를 더블클릭합니다(Mac/리눅스: `python3 serve.py`). 검은 창이 뜨면 **열어 둔 채로** 두세요. (파이썬 필요 — 5번 참고)
3. 열어 둔 페이지에서 **🔄 결정석 가격 갱신** 을 누릅니다. 도우미를 실행하지 않았다면
   "가격 갱신은 start-windows.bat를 실행한 뒤 다시 눌러주세요 (페이지는 그대로 두셔도 됩니다)" 가 표시됩니다.
4. 바뀐 가격만 목록으로 나옵니다: 보스·난이도, **현재 앱 가격 → 공식 새 가격**, 출처 공지 링크와 날짜.
   - 모두 체크된 상태이며, 원하지 않는 줄은 체크를 해제하세요. **선택한 가격 반영** 을 누르면 같은 페이지 저장소에 바로 저장됩니다.
   - 직접 수정했던 가격도 **직접 수정한 값** 표시와 함께 나오며, 반영하면 공식 가격으로 바뀝니다.
   - 공지에 적용일이 있으면(예: 검은 마법사 10/1부터) 함께 표시하고, 아직 오지 않은 날짜는 📅 **적용 예정** 으로 강조합니다.
   - 앱에서 추적하지 않는 항목은 아래 "앱에서 추적하지 않는 항목"에 따로 모아 둡니다.
   - 가격이 이미 모두 같으면 "모두 같습니다" 만 표시됩니다.
5. 끝나면 검은 창은 닫아도 됩니다.

**동작 원리** — 브라우저는 보안 정책 때문에 넥슨 홈페이지를 직접 읽을 수 없어서, 내 PC에서만 열리는 작은 도우미(`serve.py`, 파이썬 기본 기능만 사용)가
https://maplestory.nexon.com/News/Update 의 최신 업데이트 공지를 최신순으로 확인해 '강렬한 힘의 결정' 가격표가 있는 첫 공지를 읽어 옵니다.
도우미는 `127.0.0.1`(내 PC)에서만 접속을 받으며, 결과는 10분간 캐시합니다. 직접 확인: http://localhost:8787/nexon-prices

※ 가격표 해석기는 실제 2026-09-17 공지(Update/813) 원본 HTML로 46개 항목이 공식 표와 정확히 일치하는지 확인했습니다.
   다만 넥슨이 공지 형식을 바꾸면 못 읽을 수 있습니다 — 그때는 오류 내용이 표시되니 가격표에서 직접 고쳐 주세요.
